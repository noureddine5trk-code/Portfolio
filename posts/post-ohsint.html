Methodology and PoC

Phase 1: EXIF Metadata Analysis

The first step in image OSINT is inspecting embedded EXIF (Exchangeable Image File Format) metadata.

  1. Open a new tab and search exiftool then open the taskfile:

    exiftool WindowsXP.jpg

  2. Key findings from the output:

    • Artist / Copyright: OWoodflint.

This provides a primary target name: OWoodflint.

Phase 2: Social Media & Digital Footprint Reconnaissance

Using the identified name OWoodflint, perform searching to locate associated public profiles.

  1. Search Google for “OWoodflint”.
  2. Located Profile: Twitter / X account @OWoodflint.
  3. Findings from the Twitter profile:
    • Avatar Picture: A photo of a [redacted].
    • Tweet Content: A tweet containing a BSSID (MAC address) of a Wi-Fi Access Point: B4:5D:50:AA:86:41.

Phase 3: Geolocation via BSSID & Wigle.net

To determine the location and SSID of the wireless access point the target connected to, search BSSID: B4:5D:50:AA:86:41.

  • Basic Search.
  • Query Results:
    • SSID: [redacted]

Phase 4: Github Repository & Email Discovery

Searching for code repositories of OWoodflint:

  1. Search Google for OWoodflint github.
  2. Open the GitHub profile for OWoodflint.
  3. Key findings:
    • Personal Email Address: [redacted] (found on the GitHub readme).
    • Associated Site: GitHub.

Phase 5: His Holidays & Password Retrieval

From the GitHub account or search engine results, locate the target’s personal blog/website hosted on GitHub Pages or WordPress (https://oliverwoodflint.wordpress.com/).

  1. Navigate to the target’s personal website.
  2. Finding his past holiday in [redacted].
  3. View the webpage source code (Ctrl + U or right-click > View Page Source).
  4. Search deeply in <div> and <p> tags in the HTML code.
  5. Hidden content or zero-font text reveals the target password: [redacted]

Key Takeaways

  • EXIF Data: Always extract metadata from image files before conducting reverse image searches.
  • BSSID Mapping: Unique MAC addresses can be mapped globally using databases like Wigle.net or search.
  • Source Code Inspection: Web developers frequently leave unintended sensitive information in client-side HTML source code.
