hashcat -m 1000 1DFECA0C002AE40B8619ECF94819CC1B rockyou.txt

hashcat -m 160  e5d8870e5bdd26602cab8dbe07a942c8669e56d6:tryhackme                rockyou.txt

Notes

  • Q1: same length as Task 1 Q3 (64 hex → SHA-256) but not a common-password lookup hit — needs hashcat.
  • Q2: 32 hex, looks like MD5 again — this time it’s NTLM. -m 1000.
  • Q3: $6$ = SHA-512crypt (Unix shadow format). Salt is embedded in the hash itself (second $-delimited field) .
  • Q4 (the trap): hash-identifier/nth flag plain SHA-1 first, but a trailing salt means it isn’t raw SHA-1. Format as hash:salt and use mode 160 (HMAC-SHA1, key = $salt). Mode 110 (sha1($pass.$salt)), does not crack it.

Key Takeaways

  • Check length/prefix before brute-forcing: 32 hex → MD5/NTLM/MD4, 40 hex → SHA-1, 64 hex → SHA-256, $2a$/$2b$/$2y$ → bcrypt, $6$ → SHA-512crypt.
  • hash-identifier/nth can mislabel ambiguous formats (MD5 vs NTLM vs MD4) — if the “obvious” mode fails, try the next candidate on the list.
  • For salted hashes, getting the exact scheme right (pass.salt, salt.pass, or HMAC with salt-as-key) matters more than having the right wordlist — the wrong scheme cracks nothing even with rockyou.txt.
