# Noureddine TERIKI — Portfolio & blog

Personal portfolio and cybersecurity write-ups, hosted on GitHub Pages.

## Structure

- `index.html`, `about.html`, `blog.html`, `profiles.html`, `contact.html`, `404.html` — site pages
- `posts/` — write-ups and bug bounty report models
- `assets/css/style.css` — Aurora theme (night blue, violet and cyan)
- `assets/js/fx.js` — motion (animated glow, parallax, glitch, mouse glow)
- `assets/img/` — avatar and portrait images
