Takeaways

  • Four built-in Windows tools cover almost the whole investigation: Event Viewer (logons + privilege events), Task Scheduler (persistence), the registry (startup items), and Windows Firewall (opened ports).
  • The hosts file is an easy, often-overlooked spot for both C2 redirection and DNS poisoning — check it early.
  • A suspicious scheduled task’s Actions tab tells you more than its name ever will.
